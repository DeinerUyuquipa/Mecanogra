# ⌨️ MecaPro - Mecanografía y Teclado Profesional (ISO-ES)

Aplicación web interactiva, moderna y profesional para aprender y dominar la mecanografía en español con teclado estándar ISO-ES.

🌐 **Enlace en vivo (GitHub Pages):** [https://deineruyuquipa.github.io/Mecanogra/](https://deineruyuquipa.github.io/Mecanogra/)

---

## 🚀 Características

- **12 Niveles Progresivos y Más de 60 Lecciones:**
  - Nivel 1: Fila Base (ASDF JKLÑ)
  - Nivel 2: Fila Superior (QWERTY)
  - Nivel 3: Fila Inferior (ZXCVBNM)
  - Nivel 4: Fila Numérica (12345 67890)
  - Nivel 5: Puntuación Básica (`.`, `,`, `;`, `:`, `-`, `_`)
  - Nivel 6: Preguntas y Exclamaciones (`¿?` y `¡!`)
  - Nivel 7: Acentos, Tildes y Diéresis (`á`, `é`, `í`, `ó`, `ú`, `ü`, `Á`, etc.)
  - Nivel 8: Paréntesis, Corchetes y Llaves (`()`, `[]`, `{}`)
  - Nivel 9: Símbolos Especiales y AltGr (`@`, `#`, `\`, `|`, `~`, `€`)
  - Nivel 10: Operadores Matemáticos y Comparaciones (`+`, `-`, `*`, `/`, `=`, `<`, `>`)
  - Nivel 11: Código y Sintaxis de Programación (JavaScript, Python, CSS)
  - Nivel 12: Textos Reales, Redacción y Transcripción
- **Panel "¿Cómo se saca?":**
  - Muestra visualmente las combinaciones exactas (`AltGr + 2`, `Shift + '`, etc.) con explicaciones paso a paso.
- **Teclado Mecánico ISO-ES Virtual:**
  - Triple leyenda por tecla (Base, Shift y AltGr).
  - Resaltado simultáneo de modificadores y teclas objetivo.
  - Efectos visuales de switch mecánico y sonido táctil mediante Web Audio API.
- **Métricas y Estadísticas en Vivo:**
  - Palabras por Minuto (PPM), precisión porcentual, contador de errores y racha.
  - Calificación profesional al finalizar cada lección (Rangos S, A, B y C).

## 💻 Ejecución Local

Si deseas ejecutarlo localmente:

1. Clona el repositorio:
   ```bash
   git clone https://github.com/DeinerUyuquipa/Mecanogra.git
   cd Mecanogra
   ```

2. Inicia el servidor local:
   ```bash
   npm start
   ```

3. Abre en tu navegador [http://localhost:3000](http://localhost:3000).
